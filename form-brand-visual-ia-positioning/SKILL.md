# Positioning — Posicionamento estratégico

Transforma Big Idea (alma da marca) em **posicionamento operacional** que aparece em hero do site, bio, pitch, manifesto.

3 camadas:
1. **Mensagem-núcleo** — slogan de bolso (≤7 palavras)
2. **Frase de posicionamento em 4 peças** — PARA QUEM + O QUÊ + COMO + PARA QUE
3. **Reenquadramento** — 3 tipos (problema/categoria/valor) pra escapar comparação direta

---

## Step 1 — Camada 1: Mensagem-núcleo (Slogan)

Slogan de bolso ≤ 7 palavras. Deriva da Big Idea, mas mais curto + memorável.

### Critérios

```
✓ ≤ 7 palavras
✓ Memorizável em 1 leitura
✓ Reflete Big Idea
✓ Único no mercado (não saturado)
✓ Pode virar hashtag
```

### Exemplos

```
Big Idea: "Cuidado real, sem ruído"
Slogan: "Sem ruído" (2 palavras, hashtag-friendly)
OU
Slogan: "Skincare repensada" (2 palavras)

Big Idea Patagonia: "Não compre. Repare." (já é slogan)
Big Idea Apple "Think Different" (slogan direto)
```

Gera 3-5 opções de slogan. Escolhe 1.

---

## Step 2 — Camada 2: Frase de Posicionamento (4 peças)

Frase completa que articula posicionamento operacional.

### Estrutura

```
PARA [audiência específica]
O [O QUÊ — o que a marca É]
QUE [COMO — diferencial único]
PARA QUE [PARA QUE — resultado/transformação]
```

### Exemplo Aurora

```
PARA mulheres 35-45 que rejeitam complexidade artificial,
O Aurora Sérum
QUE entrega niacinamida + bakuchiol em fórmula limpa fabricada no Brasil
PARA QUE pele radiante sem rotina ruidosa.
```

### Onde usar essa frase

- Hero do site
- Bio do Instagram (versão curta)
- Pitch deck (slide 1)
- Email signature (versão curta)
- Press release intro

---

## Step 3 — Camada 3: Reenquadramento

Quando marca não consegue ser TOP 1 ou TOP 2 mental do cliente em categoria existente, ela **reenquadra** pra escapar da comparação.

### 3 tipos de reenquadramento

#### Tipo A — Reenquadramento de Problema

Muda o problema que cliente acha que tem.

```
ANTES: "Preciso de melhor sérum facial"
REENQUADRADO: "Preciso de menos produtos, não melhor sérum"

Marca não compete por "melhor sérum".
Compete por "fim do excesso".
```

#### Tipo B — Reenquadramento de Categoria

Cria categoria nova ou se posiciona em adjacente.

```
ANTES: Aurora é "marca de skincare premium"
REENQUADRADO: Aurora é "marca de ritual minimalista"

Não compete com marcas de skincare premium.
Compete em categoria nova (rituais minimalistas).
```

#### Tipo C — Reenquadramento de Valor

Muda o que "vale" no contexto.

```
ANTES: Cliente valoriza "mais ingredientes ativos"
REENQUADRADO: Cliente valoriza "menos passos diários"

Marca não compete em quantidade.
Compete em economia de tempo + simplicidade.
```

---

## Step 4 — Avaliar qual reenquadramento usar

Pra cada tipo, pergunta:

```
TIPO A — Problema reenquadrado:
"Pra audience da marca, esse novo problema é mais doloroso 
que o anterior?"

TIPO B — Categoria reenquadrada:
"Existem 2-3 marcas suficientes pra que essa categoria nova 
faça sentido?"

TIPO C — Valor reenquadrado:
"Audience aceitaria abrir mão do valor antigo pelo novo?"
```

Escolhe o reenquadramento mais viável.

Gera 3 opções de reenquadramento. Recomenda 1.

---

## Step 5 — Canvas das 5 Etapas

Estrutura analítica completa do posicionamento:

```
┌─────────────────────────────────────────┐
│  ETAPA 1 — DIAGNÓSTICO                  │
│  Onde a marca está hoje? Conhecimento,  │
│  audience, mercado, força/fraqueza      │
├─────────────────────────────────────────┤
│  ETAPA 2 — DECISÃO                      │
│  Qual posição mental queremos ocupar?   │
├─────────────────────────────────────────┤
│  ETAPA 3 — DIFERENCIAÇÃO                │
│  Como ocupamos essa posição              │
│  ESPECIFICAMENTE (não generic)?         │
├─────────────────────────────────────────┤
│  ETAPA 4 — DESIGN                       │
│  Como cada touchpoint reflete essa      │
│  posição? (visual, voice, produto)      │
├─────────────────────────────────────────┤
│  ETAPA 5 — DIFUSÃO                      │
│  Como audience descobre? Que canais?    │
└─────────────────────────────────────────┘
```

Preenche cada etapa com 3-5 frases.

---

## Step 6 — 12 Traits (Sim/Não)

Pra firmar posicionamento, lista 12 traits da marca em pares opostos.

Marca afirma 1 lado, **explicitamente nega outro**.

```
NÓS SOMOS:                NÃO SOMOS:
1. Calmos                 1. Excitados
2. Honestos               2. Sedutores
3. Editoriais             3. Comerciais
4. Acessíveis             4. Snobs
5. Atemporais             5. Trend
6. Minimalistas           6. Maximalistas
7. Premium                7. Luxo extremo
8. Brasileiros            8. Internacionais
9. Naturalistas           9. Tecnológicos
10. Femininos             10. Unisex
11. Para 35+              11. Para teens
12. Pra refletir          12. Pra ostentar
```

Audience absorve essa **clareza**. Posicionamento fica unequívoco.

## Adaptação por modo da marca

### VISUAL-ONLY
- Camada 1 (slogan) mais **visual** que verbal
- Pode ser símbolo, não palavra
- Traits mais visuais que conceituais

### VISUAL+COPY (padrão)
- 3 camadas balanceadas

### COPY-HEAVY
- Camadas verbais aprofundadas
- Frase de posicionamento mais elaborada (pode ter 2-3 versões longas)
- 20+ traits em vez de 12

## Exemplos completos

### Aurora — Positioning Premium Skincare

**Slogan:** "Sem ruído"

**Frase 4 peças:**
"PARA mulheres 35-45 que rejeitam complexidade artificial, O Aurora Sérum, QUE entrega niacinamida + bakuchiol em fórmula limpa fabricada no Brasil, PARA QUE pele radiante sem rotina ruidosa."

**Top 5 traits:**
- Somos: calmos, honestos, editoriais, minimalistas, brasileiros
- Não somos: excitados, sedutores, comerciais, maximalistas, internacionais

### Aurora — onde aplicar

- Site hero: "Aurora. Sem ruído."
- Bio IG: "Skincare minimalista. Sem ruído. 🇧🇷"
- About: parágrafo de 200 palavras
- Pitch: 3 slides de positioning

## Armadilhas a evitar

- **Slogan vago.** "Cuidamos de você" = qualquer marca. Específico.
- **Frase 4 peças genérica.** "PARA mulheres O nosso produto QUE é bom PARA QUE você seja feliz" = falha total.
- **Reenquadramento sem racional.** Mudar categoria deve ter motivo audience-driven.
- **Confundir slogan com headline.** Slogan = ID da marca. Headline = chamada de copy. Diferentes.
- **12 traits sem oposição.** Lista de "somos" sem "não somos" perde força.
- **Pular Canvas das 5 Etapas.** Apenas slogan + frase = posicionamento raso.
